Add one-line installer and comprehensive installation documentation

- Add install.sh: Lightweight automated installer for macOS/Linux
  * Detects OS and Python version
  * Clones repo to ~/.hiveterminal
  * Sets up virtual environment
  * Installs dependencies
  * Adds 'hive' command to PATH
  * Does NOT auto-install Ollama or models (user choice)

- Add install.ps1: PowerShell installer for Windows
  * Full Windows 10/11 support
  * Detects Python, Git, and Ollama
  * Clones repo to %USERPROFILE%\.hiveterminal
  * Creates hive.bat wrapper script
  * Adds to Windows PATH
  * Same features as macOS/Linux installer
