# Terminology Update Summary

## What Was Changed

Updated all references from "agentic IDE" to more accurate terminology throughout the documentation.

## Why This Change?

HiveTerminal is **NOT an IDE** (Integrated Development Environment). It's a **CLI/TUI tool** (Command-Line Interface with Text User Interface).

### What HiveTerminal IS:
- ✅ Terminal-based AI coding assistant
- ✅ CLI tool (invoked with `hive` command)
- ✅ TUI application (rich terminal interface)
- ✅ Agentic coding tool (AI agent that can read/write files, run commands)

### What HiveTerminal is NOT:
- ❌ Full IDE (no built-in editor, debugger, project management)
- ❌ VS Code extension (standalone terminal app)
- ❌ GUI application (terminal-only)
